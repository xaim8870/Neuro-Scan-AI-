# 🧠 NeuroScan AI — Brain Tumor Classification Platform

NeuroScan AI is a **full-stack deep learning application** for **Brain Tumor Classification using MRI scans**.  
It integrates a modern web interface, a production-ready backend API, and a trained deep learning model hosted on Hugging Face.

This project is designed for **research, education, and real-world AI deployment demonstrations** in medical imaging.

---

## 🔍 Key Features

- 🧠 Multi-class **Brain Tumor Classification**
- 🖼️ MRI-based **Medical Image Analysis**
- 🤖 Deep Learning model trained on a **merged MRI dataset**
- 🌐 Full-stack architecture (Frontend + Backend)
- ☁️ Model and dataset hosted on **Hugging Face**
- 🚀 Live deployment using **Vercel**
